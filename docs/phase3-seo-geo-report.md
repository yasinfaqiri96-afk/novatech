## ۴. هویت دیجیتال برند

- **نام استاندارد:** `Novatech Technology Solutions` (legalName و `name` در Organization)، نام دری **نواتیک**، نام کوتاه لاتین **Novatech**. شکل‌های «NOVATECH» و «تکنولوژی» از متن منتشرشده حذف شدند (لوگوی تزئینی ساعت صفحه تماس و تصاویر بنر دست نخوردند).

- **صفحه About** اکنون: تاریخچه (همان خط زمانی موجود)، حوزه‌ها و دو محصول، روش کار ۵ مرحله‌ای (برگرفته از فرایند منتشرشده در صفحه حسابداری)، تیم واقعی از `lib/team.ts`، نمونه‌کارها، اطلاعات تماس، ۵ پرسش همکاری. هر پاسخ FAQ واقعیتی است که در همان صفحه یا صفحات هرات/تماس/محصول از قبل منتشر شده بود.

## ۶. Structured Data و ربات‌ها

**نتیجه `npm run seo:jsonld` روی build جدید: ۶۳ URL، ۱۰۴ پرسش FAQ، بدون خطا.** روی build مرحله دوم ۶ خطا داشت (۴ تاریخ نامرئی، `/erp`، `/privacy`).

| نوع | کجا | وضعیت |
| --- | --- | --- |
| Organization + WebSite | همه صفحات (layout) | یکسان در همه صفحات (بررسی شد) |
| ProfessionalService (LocalBusiness) | `/herat`, `/contact` | بدون تغییر؛ مطابق آدرس واقعی |
| SoftwareApplication | ناظر (جدید)، مشعل fa/en/ps | ناظر فقط با featureList قابل‌مشاهده؛ بدون image و OS |
| Service + OfferCatalog | صفحات خدمات | نام‌ها با کاتالوگ Organization یکسان |
| FAQPage | ۲۷ صفحه، از جمله اکنون `/` و `/about` | همه پرسش و پاسخ‌ها در HTML دیده می‌شوند (تست خودکار) |
| BreadcrumbList | همه جز `/` | موقعیت‌ها و URLها معتبر |
| BlogPosting | ۱۹ مقاله | author = Organization (نویسنده فردی ثبت نشده)، `dateModified` قابل‌مشاهده |
| Person | ۳ عضو تیم | حالا هر `@id` به کارت قابل‌مشاهده در `/about` می‌رسد |

FAQPage در Google برای اغلب سایت‌ها دیگر Rich Result نمایش نمی‌دهد؛ ارزش آن اینجا ساختار پرسش‌وپاسخ برای موتورهای پاسخ‌گوست، نه نتیجه تزئینی.

**ربات‌ها (از کد):**

- `robots.txt`: `User-Agent: *`, `Allow: /`, `Disallow: /api/`, Sitemap. Googlebot، Bingbot، OAI-SearchBot، GPTBot، PerplexityBot و Google-Extended همه از قانون `*` پیروی می‌کنند و مسدود نیستند. گروه اختصاصی برای هیچ رباتی ساخته نشد چون جایگزین قانون `*` همان ربات می‌شود.
- Middleware یا قانون User-Agent در کد وجود ندارد؛ درخواست با User-Agent ربات‌های OAI-SearchBot و bingbot به build محلی پاسخ 200 گرفت.
- **WAF/Cloudflare از کد قابل بررسی نیست.** `DEPLOYMENT.md` استفاده از Cloudflare را تأیید می‌کند. پس از Deploy در داشبورد Cloudflare بررسی شود: Bot Fight Mode / Super Bot Fight Mode، قوانین WAF، «Block AI bots» و AI Crawl Control. این گزینه‌ها می‌توانند OAI-SearchBot یا PerplexityBot را بدون اطلاع سایت مسدود کنند.
- همه صفحات Static/SSG هستند؛ متن خدمات، محصولات، FAQها و بخش جدید صفحه اصلی بدون اجرای JavaScript در HTML وجود دارند (inventory از HTML خام گرفته شده است).
- `llms.txt`: ساخته شد، ایستا، فقط از داده‌های سایت و URLهای Canonical. هیچ موتوری خواندن آن را تضمین نکرده و هیچ تأثیری برای آن ادعا نمی‌شود.
